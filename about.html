About Holiday Planner

The Holiday Planner is a simple web application designed to help you manage your holiday tasks, groceries, and gift lists all in one place. It uses AWS DynamoDB for storing your data, and JavaScript for handling interactions on the front end.

Features include:

  • Adding, viewing, and deleting tasks.
  • Managing grocery items for holiday meals.
  • Keeping track of gift ideas and recipients.
  • Secure input with sanitization to prevent unsafe content.
  • Real-time previews on the home page.

This project was built as part of CS 408 to demonstrate web development skills, AWS integration, and front-end JavaScript interactivity.
